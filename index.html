Combat Log Parser

Combat Log Watcher Load a combat log, then watch that same file to keep the report current while WoW is running. The watcher starts at the file's current end, checks for newly appended data, and sends only complete new log lines into the parser. New fights and statistics appear automatically without reloading the whole file. It never changes the log or uploads it anywhere. Watching stops when you press Stop, close the app, or the file becomes unavailable.
